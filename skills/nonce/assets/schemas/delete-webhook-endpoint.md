# DeleteWebhookEndpoint

deleteWebhookEndpoint — destructive

Required: `workspace_id`, `endpoint_id`

## Purpose

Delete Webhook Endpoint

Delete your webhook endpoint. Deliveries still waiting to be sent are cancelled.

## Code

```js
const result = await nonce.deleteWebhookEndpoint(input, {
  confirmDestructive: true,
  confirmation: "<confirmed target and effect>",
})
```

## CLI

```bash
"$NONCE_NODE" "$NONCE_SKILL_HOME/scripts/nonce.mjs" call deleteWebhookEndpoint --input-file ".nonce/requests/delete-webhook-endpoint.json" --allow-destructive --confirmation "<confirmed target and effect>"
```

## Input

```ts
export interface DeleteWebhookEndpointInput {
  workspace_id: string
  endpoint_id: string
}
```
